**pydata-hugo-theme** is a [Hugo Module](https://gohugo.io/hugo-modules/) port of the [PyData Sphinx Theme](https://pydata-sphinx-theme.readthedocs.io/en/stable/) — a generic, site-agnostic theme for any Hugo project, with no branding or content baked in.

This site is itself built with the theme (see the sidebar), so everything you see here — the navbar, sidebar, search, dark mode switcher, footer — is the theme working out of the box with no site-level template overrides.

## Where to start

- **[Get started → Install](/get-started/install/)** — add the module to your site and get it building.
- **[Get started → Layout](/get-started/layout/)** — understand the header/sidebar/footer slot system before diving into individual options.
- **[Feature parity with upstream](/feature-parity/)** — what the original Sphinx theme has that this port doesn't (yet).
